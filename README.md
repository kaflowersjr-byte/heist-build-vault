# Heist Build Vault

Unofficial PAYDAY 2: Crimewave Edition build planner and PS4 progress tracker for Android.

## Latest Version

**v3.0.3**

### Download

Download the latest Android APK from the Releases page:

**HeistBuildVault-v3.0.3.apk**

GitHub Releases:
https://github.com/kaflowersjr-byte/heist-build-vault/releases/latest

## Features

- Create and save multiple builds
- Plan all five skill trees
- Level-based skill point limits
- Infamy I+ skill-tree support
- Perk deck planning
- Primary and secondary weapon loadouts
- Weapon modification planning
- Armor, deployable, throwable, and melee selection
- DLC ownership tracking
- PS4 trophy progression tracking
- 40-heist difficulty trophy tracker
- Hard, Very Hard, OVERKILL, and Death Wish progression
- Local-only build and progress storage

## Android Requirements

Android 8.0 or newer.

## Installation

1. Open the latest GitHub Release.
2. Download `HeistBuildVault-v3.0.3.apk`.
3. Open the downloaded APK.
4. Android may ask you to allow installation from your browser or file manager.
5. Install and launch Heist Build Vault.

## Privacy

No account is required.

Heist Build Vault does not use advertising or analytics services.

Builds, DLC selections, trophy progress, and heist progress are stored locally on your device.
